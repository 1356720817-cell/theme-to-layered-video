# 制作流程

## 换主题时重新做什么

用户只给主题即可开始。默认约130秒、中文、横屏、音乐驱动；其他可选参数为受众、时长、比例、配音、风格与事实范围。没有这些参数时按默认值执行并说明，不能反复把选择题推回用户。

结构随主题变化：历史/品牌沿革用时间线；咖啡/生产制造用流程；汽车/科学知识用“问题—机制—证据—应用”；产品展示用使用场景和细节。主题完全不同，不能只替换旧片标题、保留旧文物或旧分镜。

## 1. 内容与来源

先确定中心论点、关键事实和观众最后记住的一句话，再形成全片节奏。新主题的一切具体实体重新研究。建立sources记录：claim、source_url、source_type、verified、limitations。优先官网、博物馆、原始论文、数据集或一手文献；无法核验的部分不能用精美生图伪装成证据。

原书法/古籍真实图像优于普通字体拼字；现代原子坐标优于随机球棍假结构。失传作品的后世摹本须说明身份；现代科学结构不冒称历史实验样品。没有合适原始资产时用明确的视觉演绎。

## 2. 先定分镜，再定素材

每镜写清：目的、屏幕文字、信息层级、主体、环境、前景、运动、来源和时段。不要用“山水/草木/建筑”一个泛型键给多个阶段调用同一张图。素材用独立assetId和ownerShot绑定；entityId可以相同，assetId和画面应不同。

例：两个时期都讲稻作，早期用低地田野与原始聚落，现代用试验田与研究者，分别生成底图和稻穗前景。章节图和随后器物特写也应是不同画面。结尾回顾在shot的section中标为recap，不能仅因“出现在后半段”就默认允许重复。

先做3种锚点：纹理细节多的主体、具有遮挡和纵深的场景、最复杂的连续切换。看成片尺寸和连续帧，不仅看生图工具给的漂亮大图。

## 3. 生图和素材

按镜头列出需要的独立资产：背景、主体、近景、必要水面/烟雾/反射；没有可独立运动的内容，不要为凑图层数量拆分。光照、视角、尺度和色温在合成前就要一致。

提示词骨架：用途；准确主体和时期；材料/结构；构图留白；光线；画风；可见细节；不应出现的现代元素；是否真实透明；不要生成的文字。不要笼统只写“高清、电影感”。保存实际调用提示词，失败或弃用版本不算正式素材。

主体材质、轮廓、建筑结构、手部、叶片和粒子细节逐项看。不要把低质量生成图放大后称为高清。不能借镜头运动掩盖物品粗糙。透明图应检查真实alpha与边缘色晕，不能把黑底当透明底。

生成的长篇文字通常不可靠：标题和引文独立排版；需要实际书法笔势时使用有来源的书法图像。照片、古籍和PNG保留原件，剪裁和构图尽量在可编辑工程内完成。

## 4. 音乐与配音

当前主题重新定音轨。默认无需口播，有口播时先拿到真实音频再按其时长安排镜头、字幕。估算时长只能用于草稿，不能声称已完成对齐。

片头按音乐明确事件设计：主标题、词组进入、重拍强调、主体或亮度冲击、进入正片。多组文字在不同拍进入，不能只做同一段淡入后加循环闪动。记录cue的帧号与依据。自动瞬态候选不是已确认的节拍。

原始参考片的音轨不作为后续主题的默认音乐库。后备脚本只能产生标明“临时”的基础节奏，不能自动成为最终配乐。按music.md和approvals.md准备具体试听确认后再锁定全片。

## 5. 组织工程和恢复

production.json最少记录stage、updated_at、topic、completed_shot_ids、pending_shot_ids、selected_assets、audio、checks和next_action。每完成一个阶段写一次。恢复时读取它与现有素材，不从头重复生图。

默认阶段：brief → research → storyboard → anchors → assets → motion → preview → render → qc → delivered_pending_acceptance → accepted。阶段不是每步要批准的闸门；用户确认政策由review-ledger单独记录，accepted必须有对应版本的实际认可。

starter只提供可编辑基础，初始化时status=draft。代理必须完成主题研究、全片分镜和正式素材，再把status改为ready。不得把“替换占位图”之类未完成项目伪装成主题视频。

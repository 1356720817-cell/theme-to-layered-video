# 验收矩阵

| 阶段 | 具体提交物 | 谁确认 | 通过条件 |
|---|---|---|---|
| 内容 | brief、脚本、来源、逐镜信息 | 默认代理；用户要求则用户 | 主题/事实/顺序清楚，来源与不确定性有记录 |
| 音乐 | 具体歌曲版本、选段/音量、覆盖高潮的有声预览 | 默认用户；明确委托可代理 | 选择绑定实际文件与参数，确认在有效范围内 |
| 视觉锚点 | 难主体细节、真分层、连续切换样片 | 默认用户；明确委托可代理 | 清楚主体、透明边缘、遮挡与独立运动成立 |
| 全片预览 | 开头5秒、高潮前后、至少一处季/章转换、结尾 | 默认代理；按用户确认政策 | 音乐不突兀、重音有依据、镜头节奏合适 |
| 最终技术 | audit、lint/TS、ffprobe、全解码、音轨核验 | 机器 | 真运行、绑定当前输入及最终MP4哈希 |
| 最终视觉 | 最终编码的每镜起/中/末、所有边界、重点连续片段 | 代理或实际审阅者 | 无粗糙主体、漏边、黑闪、错字、文字重影 |
| 封面（要求时） | 具体参考、标题/人物决定、各比例完整图 | 按用户要求 | 每比例独立构图、字无错、缩略图可读 |
| 交付与认可 | MP4、预览、工程ZIP、检查范围 | 用户最终认可 | 可先送达；accepted须另有明确对应版本认可 |

## 有限质量门槛
- 工程：非draft，时间轴连续，所有引用可移植。正文每个主体独立资产；回顾复用显式标recap/ending。哈希只抓完全重复，近似改图还须人工对比。
- 素材：在输出尺寸看真实细节、器物/古籍/结构、光向和alpha。放大低清不算高质量。图片有2–3层不等于有独立动画。
- 节奏：单/双/三层按内容混用；不固定数量比。每镜有运动目的。默认提示连续3次推近需审阅，不机械轮换。需要持续的火/水/风等主体不能意外断灭，卡点幅度按实际重音变化。
- 字幕/诗词：正确来源，读得完，留白有目的；章标题、年代、引文与图像转场独立。连续尾部关闭旧标签。
- 音频：源音频和实际选段有文件；开头不突兀，高潮目标合理，淡变无截断，音量经实际试听。自动相关性、峰值或节拍网格不是人工听审。
- 复核取样：除verify_media的中点和边界[-1,0,+3,+8]外，每镜首/末和开头1秒、3秒、5秒、高潮前后、复杂分层画面以高清查看；高运动/有疑点段连续播放。只做接触表检查不能声称逐帧全片观看。
- 音轨与画面整段审阅受工具限制时，明确列出未做项；可交付待用户验收版本，不能把未做项标passed。
- 打包：CRC、文件清单、源码/资产/提示词/来源/字体/音轨说明、依赖锁和重导出入口；不带node_modules、缓存、密钥。可用锁定依赖时在隔离目录试重导出，无法离线重导出则如实注明。
- 封面不预设大金字、圆环、四季或任何主题外装饰；从用户实际喜欢的画面提取构图与质感。用户只选风格不等于最终认可图片。

## 执行顺序
```text
python -I scripts/audit_project.py .
npm run lint
python -I scripts/production_gate.py check . --stage render
# 实际render和mux
python -I scripts/verify_media.py . --video outputs/final.mp4
python -I scripts/verify_audio.py . --video outputs/final.mp4
# 查看最终文件取样/连续片段，实际审阅后record visual，指定最终MP4和审阅记录
python -I scripts/production_gate.py check . --stage deliver --video outputs/final.mp4
python -I scripts/package_project.py . --video outputs/final.mp4 --output <新版本工程.zip>
```
production_gate不代替lint、渲染、美术、来源或听审。脚本通过只表示它能验证的有限条件。warnings逐条处理/解释，不通过改门槛或改status掩盖问题。

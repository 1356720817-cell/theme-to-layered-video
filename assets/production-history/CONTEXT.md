# 本次制作历史：只作实现证据

scripts/保存这次实际使用过的规划、生图清单、音乐改版、布局、诗词与检查脚本；generated-records/和generated-batches/保存实际生成记录。scene-plan、music-sync和fuguang-analysis保留原始分析。

这不是初始化模板。这些历史脚本有二十四节气、30fps、77秒起点、128秒、25秒主段、具体文件名和实际工程结构的硬编码。部分依赖numpy或原商业音源；音乐母带没有随skill分发。不要在本目录直接执行，不要拷贝成新主题的默认脚本，不把其中自动analysis/passed字段当作新项目已经通过。

需要查一项实现如何得到时，读对应历史脚本，再把确需复用的机制参数化到当前新工程。通用可执行工具在skill根目录scripts/，原始视觉案例在assets/solar-terms-case/。

原始基础节奏和早期方案属于被替换的尝试，保留是为了说明为什么需要实际试听确认；它们不是推荐最终配乐。

# theme-to-layered-video

将一个主题或参考短片制作成有专属素材、分层动画和音乐卡点的叙事视频，并交付可编辑工程。

这个 Skill 保留了“文明之火”完整参考片及《二十四节气》实际制作案例。它适合知识、历史、自然与文化类图像叙事，也可依新主题重新制定视觉方案。

## 包含什么

- 130秒“文明之火”参考视频：视频与项目中保存的独立音频合成，作为参考资料。
- 128秒《二十四节气》完整视觉标尺：从仓库的 Release 下载，文件为静音视觉参考。
- 实际可编辑案例：26个镜头、44张分层素材、生成提示词、镜头参数和历史制作记录；案例使用静音占位音轨。
- 通用 Remotion 模板：独立前后景、轻摆、重音回弹、天气、字幕/引文、可配置开头与分屏结尾。
- 制作规程：参考拆解、资料核验、分镜、选曲试听、动效预览、修订、封面和验收。
- 可执行工具：工程初始化、参考取样、音乐处理与测量、版本确认记录、媒体检查和工程打包。

## 开始使用

克隆整个仓库，并将目录放入你的 Skill 环境指定的位置，保留目录结构；例如在 Codex 中可放到用户级 skills 目录，确保 `SKILL.md` 位于技能目录根部。

首次使用完整《二十四节气》视觉标尺时，在技能目录运行：

```bash
python -I scripts/prepare_benchmark.py
```

脚本从 [v2.0.0 Release](https://github.com/1356720817-cell/theme-to-layered-video/releases/tag/v2.0.0) 获取完整静音视觉标尺，下载后校验 SHA-256；已存在同哈希文件时不会重复下载。没有网络或下载失败时，保留原片与工程可用的部分，并如实说明缺失的标尺。

制作视频通常还需要 Node.js、FFmpeg、ffprobe、Python 与 Pillow，以及可用的图像生成能力。Remotion 依赖版本由模板的 `package-lock.json` 锁定。运行环境和模型能力会影响实际效果。

## 调用示例

```text
使用 $theme-to-layered-video，主题：茶从种子到一杯。

先分析完整参考片与成片标尺，重新研究这个主题。
配乐先让我确认实际选段、音量和高潮位置；
代表动效样片确认后再制作全片。
交付MP4、可编辑工程、素材提示词和验收记录。
```

可指定比例、时长、风格和旁白。需要逐镜确认时直接说明；已经明确委托代理处理的步骤不会重复要求确认。

## 工作流程

1. 研究主题并拆解参考：区分可复用的镜头机制与原片题材。
2. 编写内容、来源和逐镜计划，制作高难度主体与分层动效样片。
3. 选曲并提交真实有声试听，确认版本、选段、音量、淡变和高潮位置。
4. 分批制作独立素材，逐镜安排前景、主体、背景、文字和镜头运动。
5. 检查开头、高潮、连续切换及结尾，完成正式渲染与音轨合成。
6. 对最终编码文件执行解码、时间轴、素材去重、透明度、音频与画面审阅。
7. 交付视频、可编辑工程、提示词、来源与实际检查范围；用户确认后记录最终验收。

正常叙事镜头不复用相同主体图；明确标注的结尾回顾可复用。音乐、样片和验收记录绑定具体文件，文件变化时需要重新检查相关部分。

## 参考资料及许可范围

“文明之火”原片由发布者表示拥有公开再分发授权。二十四节气成片标尺使用静音版本，案例中的占位音轨为生成的静音；案例不提供《浮光》商业母带。下一主题应重新选择音乐与主体素材。

本仓库暂未指定统一开源许可证；请分别核对素材来源和使用条件。

## 已验证的范围

- 28项行为测试覆盖素材重复、假透明、音轨与试听文件变化、高潮映射、逐镜确认及过期记录等。
- 使用生产引擎与案例素材渲染14秒1080p片段，完成解码、抽帧及音轨一致性检查。
- 可编辑工程在另一个目录重新导出，测试片的最终文件哈希一致。

测试不保证新主题的生成图片、音乐审美或所有平台的效果。完整操作细节见 `references/detailed-production.md`，验收标准见 `references/acceptance.md`。
